# Linux 开发板项目工作约束（接入时合并到项目 AGENTS.md）

- 采用 `standards/linux-board-release/v1.0.0/SPEC.md`，记录本项目实际 board profile 和适配工具。
- 应用、用户态适配和文档在应用仓库；驱动、设备树、启动、板级集成及镜像构建在对应硬件仓库。
- 新板或发布任务使用 `skills/linux-board-release/SKILL.md`。已有用户授权继续有效，Skill 不扩大任务范围。
- 保留实际 API/ABI、安装路径、状态格式；变更说明兼容和迁移，不默认所有板使用同一 SDK 或显示栈。
- UI 更改同步真实源码截图，标明渲染/实拍及来源；不启动真实板级网络服务来制作宿主机截图。
- 修改逻辑/工具运行项目测试；修改目标代码做对应架构编译；硬件效果按本次镜像执行板端验证。
- 发布固定应用与硬件提交、SDK 输入及实际镜像哈希；核对镜像内应用标识，记录真实验收结果。
- 未测不能写 passed，缺少来源/输入/发布证据不能改字段绕过门禁。草稿不得描述为公开正式下载。
- 发布前校验远端实际附件及标签/包配方；不移动发布标签，不覆盖公开镜像，失败重试先检查远端状态。
- 固件进入应用 Releases；安装入口统一 `https://github.com/dshanpi/lynx-releases`。
- 不提交真实密码、凭据、个人设备数据或构建产物到 Git。新规范通过版本升级引入，旧发布证据不得重写。
