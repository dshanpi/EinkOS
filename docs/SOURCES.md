# 系统源码与第三方组件

EinkOS 是应用层项目；配套系统由 Linux、OpenWrt、硬件驱动、Bootloader 和
厂商运行库共同组成。应用采用 GPL-3.0-only，不意味着镜像所有组件都采用相同许可证。

- 应用、构建脚本、固定 LVGL 源码和字体子集：本仓库及每个 Release 的完整源码包。
- EPD 内核驱动、设备树、板级配置和系统集成：
  https://github.com/DongshanPI/100ASK_T113-PRO_TinaSDK5/tree/einkos-240x360
- 完整系统基线：TinaSDK 5.0 v1.2。覆盖层不能替代完整 SDK 源码。
  每个镜像的 `build-info.json` 记录实际使用的 SDK 各仓库提交和本地修改情况。
- 字体保留 OFL；LVGL 保留 MIT；内核/UAPI 保留各自原始许可证和 syscall note。

发布系统镜像前，需要提供与该镜像匹配的系统组件源码获取位置，包括内核、
OpenWrt 包及其补丁和构建配置。不能用本仓库应用源码包代替整个系统的对应源码。
对不能公开访问的 SDK 基线，应补充可下载的对应源码包；不要仅提供私有仓库提交号。

镜像中的 OP-TEE、启动固件、Wi-Fi 固件及 btmanager 等厂商组件，应按实际来源
列明许可证和再分发依据。原硬件项目中存在文件不等于已确认其再分发条件。
在对应源码和厂商分发信息未齐备之前，可以发布应用源码，系统镜像资产保持本地
或 Draft，不对外标记为完成发布。实机验收未完成时也不得标记为稳定版。
