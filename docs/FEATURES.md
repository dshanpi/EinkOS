# 核对系统特性

本页用于判断当前 EinkOS 是否满足应用需求。表中“已实现”指仓库存在对应代码；目标硬件的验证状态需另查该镜像的验收记录。

## 查看已实现功能

| 功能 | 当前行为 | 使用限制 | 代码入口 |
| --- | --- | --- | --- |
| 黑白桌面 | 日期、星期、农历、连接状态和四个应用入口 | 固定 240×360 布局，11 个页面路由 | [main.c](../src/main.c)、[ui.c](../src/ui.c) |
| 按键导航 | K1/K3 移动，K2 确定，K2 长按返回 | 主机编译不提供交互式设备模拟器 | [input.c](../src/input.c) |
| 日历 | 月份浏览、今日定位、农历和节日 | 农历转换范围 1900–2100 | [lunar.c](../src/lunar.c) |
| TXT 阅读 | UTF-8/BOM；无效 UTF-8 尝试 GB18030 转换；翻页、续读、单书签 | 最多 128 个文件、两层子目录、单文件 32 MiB；不支持 PDF/EPUB | [reader.c](../src/reader.c) |
| Wi-Fi 配网 | 扫描、手机热点配网、隐藏 SSID、成功或退出后恢复 STA | Tina XR829 环境；STA/AP 切换会暂时断开原网络 | [connectd.c](../platforms/tina/connectd.c) |
| 蓝牙管理 | 开关、扫描、配对、PIN/passkey、连接及断开 | 依赖匹配厂商库和 ttyS1；缺失时显示不可用；不等于支持任意蓝牙应用协议 | [connectd.c](../platforms/tina/connectd.c) |
| 系统资源 | CPU、内存、磁盘、温度、网络状态 | 可读项取决于目标 Linux 接口 | [system_stats.c](../src/system_stats.c) |
| 屏幕诊断 | 刷新计数、模式和错误信息 | 需要配套 EPD 驱动 ioctl | [epd_disp.c](../platforms/tina/epd_disp.c) |
| 配置与语言 | 按键映射、中英文主页、刷新周期、状态路径 | 部分内部提示仍为中文；字体子集存在缺字限制 | [settings.c](../src/settings.c) |
| 时间恢复 | 保存时间、构建时间兜底；浏览器上传时间和 NTP 校时 | 断电恢复不代表时间准确；当前状态还含联网启发式判断 | [time_state.c](../src/time_state.c) |
| 墨水屏刷新 | 菜单选择通常使用 DU，页面切换和阅读翻页使用 GC | 默认 60 秒更新状态、10 次局刷后全刷；不属于视频刷新 | [main.c](../src/main.c) |
| 服务管理 | procd 分别管理桌面与连接服务 | IPC 当前为同步调用，网络操作仍可能等待 | [服务脚本](../packaging/openwrt/eink-dashboard.init) |

## 区分已实现接口与桌面入口

连接协议还包含忘记 Wi-Fi、移除蓝牙设备等命令，但桌面没有为所有协议命令提供独立操作入口。不能仅凭协议枚举判断某个菜单已经存在。

显示接口提供 GC、DU 和 5S 刷新模式。常规桌面策略主要使用 GC/DU，5S 接口的存在不代表桌面提供独立的 5S 切换入口。

## 确认尚未支持的能力

| 能力 | 当前状态 |
| --- | --- |
| OTA、在线自动更新、应用回滚 | 发布规范已有要求，设备更新器及相应应用发布工具尚未实现 |
| 更多 Linux 板卡和屏幕尺寸 | 有接入规范，尚不能视为已完成适配 |
| 通用 framebuffer、Wayland/X11 桌面 | 当前没有相应显示或窗口后端 |
| 动态插件和任意 Linux 应用窗口 | 当前使用固定页面和应用逻辑 |
| 连续灰阶图像、视频显示 | 当前输出为固定分辨率的 1bpp 黑白帧 |

需要新增能力时，先在[架构说明](ARCHITECTURE.md)中确认接口边界，再按[开发要求](DEVELOPMENT.md)实现和验证。
