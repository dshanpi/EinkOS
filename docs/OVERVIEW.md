# 认识 EinkOS

EinkOS 是面向墨水屏设备的开源 Linux 桌面与应用集合。当前适配 **100ASK T113-PRO、3.52 英寸 240×360 单色墨水屏和 TinaSDK / OpenWrt 系统**。

通过三个物理按键使用日历、TXT 阅读器、Wi-Fi 配网和蓝牙管理；在诊断页面查看系统资源与屏幕刷新状态。

## 核对版本状态

截至 2026-11-12，[v0.1.0 发布页](https://github.com/dshanpi/EinkOS/releases/tag/v0.1.0)标记为 **Pre-release（预发布）**，提供配套资料和镜像附件。发布说明仍列有未完成的实机验证及系统来源材料要求。

安装前核对该版本的发布说明、`validation.json`、`release-lock.json` 和 `SHA256SUMS`。页面上出现下载按钮不代表该镜像已通过稳定版验收，文档更新也不会改变历史镜像的应用提交。

## 了解支持范围

[系统特性表](FEATURES.md)按实现入口列出功能和限制。当前没有 OTA 更新器、通用 PC 桌面、动态应用加载器或已验收的其他分辨率后端。

[界面图库](GALLERY.md)展示生产 UI 的主机渲染结果，使用固定演示数据；它用于了解界面，不代表真实墨水屏刷新效果或硬件验收记录。
