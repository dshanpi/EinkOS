# 定位常见问题

先记录开发板型号、镜像版本、`eink-dashboard --version` 输出及复现步骤。以下命令在目标板 Linux 串口终端执行；无法进入 Linux 时先保留完整启动日志。

## 检查 LYNX 无法识别或烧录失败

确认使用支持数据传输的 USB 线、目标下载接口及正确 USB 驱动，重新扫描并核对物理路径。FEL/FES 设备与调试串口分别绑定。

能进入配套 U-Boot 时，可按[烧录说明](INSTALL.md)使用 `efex`；不能进入时按硬件说明操作下载按键。不要在 Linux Shell 执行 `efex`。

烧录失败时保留工具日志，区分设备未识别、Loader 不匹配、传输中断和校验失败。任务终态未知时先查询状态，不反复写入。

## 检查屏幕没有桌面

```sh
ls -l /dev/epd_100ask
dmesg | grep -Ei 'epd|spi|gpio'
logread | grep -i eink
```

| 结果 | 下一步 |
| --- | --- |
| 没有 EPD 设备节点 | 核对镜像板型、设备树 SPI1/GPIO、内核驱动和硬件连接 |
| 探测等待约 30 秒后失败 | 检查 BUSY、复位、DC 和 SPI 信号 |
| 有设备节点，桌面服务反复退出 | 查看首条应用错误，核对文件、字体、权限和 ABI |
| 桌面运行，但方向或黑白不正确 | 核对 240×360、1bpp、MSB first、白色为 1、单帧 10800 字节 |

当前转接板 BUSY 为 PD22，空闲时高电平；RESET 为 PD13，DC 为 PB5。详细接线见[硬件说明](HARDWARE.md)。

若镜像包含硬件诊断工具，可先停止桌面，避免两个进程同时写屏：

```sh
/etc/init.d/eink-dashboard stop
epd-test info
epd-test checker
/etc/init.d/eink-dashboard start
```

检查工具输出和实际棋盘格。若无 `epd-test`，不要把“命令不存在”判断为屏幕驱动故障；该工具由硬件仓库提供。

## 检查按键没有响应

```sh
cat /proc/bus/input/devices
ls -l /dev/input/event*
cat /etc/eink-dashboard.conf
```

确认输入设备存在，再核对按键事件码与配置。默认上一项为 115，下一项为 373，确定为 119；28 和 114 是兼容映射。当前应用扫描 event0–7，超出此范围需要调整输入适配。

K2 长按约 1.2 秒并在松开后判定。在主页长按切换语言，在应用内长按执行返回；操作位置不同，结果不同。

## 检查手机配网页打不开

1. 确认桌面仍显示手机配网热点和密码。
2. 确认手机连接的是该热点，必要时关闭自动切换到其他 Wi-Fi。
3. 在浏览器手动打开 `http://192.168.5.1`。
4. 热点已超时退出时，从桌面重新开始配网。

STA/AP 切换期间原网络中断属于当前方案行为。配网失败时检查目标 SSID、密码及厂商 Wi-Fi 日志；保存日志前移除凭据。

## 检查蓝牙显示不可用

```sh
ls -l /dev/ttyS1
logread | grep -Ei 'eink|bluetooth|btmg'
```

核对镜像是否包含匹配的 `libbtmg.so`、XR829 蓝牙串口和相关驱动。不要复制其他板卡的厂商库直接替换。

缺少蓝牙能力时桌面应降级显示“不可用”。如日历或阅读器也无法操作，另外检查桌面/IPC 错误。

## 检查书籍未显示或续读失效

确认扩展名为 `.txt`，位于 `/mnt/UDISK/books`、`/mnt/SDCARD/books` 或其两层子目录，单文件不超过 32 MiB，索引总数不超过 128。

重新扫描书库。修改文件大小、时间或路径后，旧阅读位置可能不再适用；不要据此判断状态文件损坏。

## 检查时间不准确

先在串口执行 `date`，再核对配置中的时区。断电恢复时间和准确同步时间是不同状态；通过手机配网页或 NTP 再次校时，并与可信时钟比较。

当前连接状态可影响“准确”标记，因此不能只看该标记判断 NTP 已成功同步。

## 提交可复现的问题

在 [EinkOS Issues](https://github.com/dshanpi/EinkOS/issues)提供板型、镜像版本及哈希、应用提交、复现步骤、预期结果与实际结果。驱动探测或引脚问题同时关联硬件仓库；工具识别问题关联 LYNX。

只附必要日志，移除 SSID 密码、令牌、个人设备地址和阅读记录。
